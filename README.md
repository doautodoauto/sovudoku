# Совудоку: Тайны Хогвартса

Логическая головоломка в мире Гарри Поттера (PWA, работает офлайн).

## Структура
```
index.html             — игра (код, стили, уровни)
sw.js                  — service worker (офлайн-кэш)
manifest.webmanifest   — манифест PWA
icon-180/192/512.png   — иконки
assets/img/*.webp      — фоны и иллюстрации
assets/fonts/*.woff2   — шрифты
```

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите **содержимое** этой папки в корень (не саму папку).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. Через минуту игра будет доступна по адресу `https://<логин>.github.io/<репозиторий>/`.
4. На iPhone: Safari → «Поделиться» → «На экран „Домой“».

Файл `.nojekyll` уже лежит в корне, чтобы GitHub не обрабатывал сайт Jekyll'ом.

## Обновление игры
При любом изменении файлов поменяйте версию кэша в `sw.js` (`const C='sovudoku-v5'` → `v6` и т. д.), иначе у игроков останется старая версия.

## Что нового
- **Оптимизация**: режим «Энергосбережение» (включается автоматически на телефонах, переключатель в «Опциях»), анимации и эффекты останавливаются на скрытых экранах и при сворачивании, картинки и шрифты вынесены из HTML (index.html: 1,36 МБ → 0,3 МБ), реже сохранение и сетевой трафик, звук засыпает в тишине.
- **Школа мракоборцев** — 100 новых испытаний средней сложности (9×9 – 11×11), между основными курсами и Запретной секцией. Доступна сразу; испытания открываются по порядку.
- **Таблица рекордов** — кнопка «Рекорды» в меню: игроки, дата первого и последнего визита, число визитов, время в игре, пройденные уровни по разделам, звёзды. Работает при включённой «Совятне онлайн».

Таблица хранится в публичном MQTT-брокере (retained-сообщения), без своего сервера: это бесплатно, но брокер не гарантирует вечное хранение. Прогресс каждого игрока хранится у него на устройстве и при подключении снова отправляется в таблицу.
