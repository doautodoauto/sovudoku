# Совудоку: Тайны Хогвартса

Логическая головоломка в мире Гарри Поттера (PWA, работает офлайн).

## Структура
```
index.html             — игра (код, стили, уровни)
sw.js                  — service worker (офлайн-кэш)
manifest.webmanifest   — манифест PWA
icon-180/192/512.png   — иконки
assets/img/*.webp      — фоны и иллюстрации
assets/fonts/*.woff2   — шрифты
```

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите **содержимое** этой папки в корень (не саму папку).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. Через минуту игра будет доступна по адресу `https://<логин>.github.io/<репозиторий>/`.
4. На iPhone: Safari → «Поделиться» → «На экран „Домой“».

Файл `.nojekyll` уже лежит в корне, чтобы GitHub не обрабатывал сайт Jekyll'ом.

## Обновление игры
При любом изменении файлов поменяйте версию кэша в `sw.js` (`const C='sovudoku-v6'` → `v7` и т. д.), иначе у игроков останется старая версия.

## Режимы
- **Курсы Хогвартса** — 98 уровней + 2 тайных (5×5 – 10×10).
- **Хогсмид** — 100 лёгких заданий (7×7 – 9×9), 5 кварталов.
- **Школа мракоборцев** — 100 испытаний средней сложности (9×9 – 11×11), 5 ступеней.
- **Запретная секция** — 100 трудных задач с проклятиями (11×11 – 13×13).
- **Дуэльный клуб** — гонка на одном поле: против Невилла, Драко и Беллатрисы (без интернета) или против живого игрока через Совятню.

Все новые уровни проверены: решение единственное и находится логикой, без угадывания.

## Таблица рекордов
Обновляется сама при входе в игру, при возвращении в неё и каждые несколько минут — даже если «Совятня онлайн» выключена (подключение короткое, ~15 секунд). Отключить показ своих результатов: Опции → «Таблица рекордов».

Хранится в публичном MQTT-брокере (retained-сообщения), без своего сервера: бесплатно, но брокер не гарантирует вечное хранение. Прогресс игрока лежит у него на устройстве и при входе снова отправляется в таблицу.

## Энергосбережение
Режим включается автоматически на телефонах (Опции → «Энергосбережение»): без размытия, бесконечных анимаций и тяжёлых эффектов; анимации останавливаются на скрытых экранах и в свёрнутой игре.
